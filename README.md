## 🚀 주요 기능

- **Smooth Scroll** – 메뉴 클릭 시 해당 섹션으로 부드럽게 이동
- **Active Menu Highlight** – 현재 선택된 메뉴 아이템 강조
- **Responsive Hamburger Menu** – 모바일 환경에서 메뉴 열고 닫기
- **Portfolio Category Filter** – 프로젝트 카테고리별 필터링
- **Scroll to Top Button** – 일정 스크롤 이후 상단 이동 버튼 표시
